# 查阅：引擎常用组件一览

前面我们手写过 `UMySceneComponent`（[第 14 章](/C++/14.实战-把视线检测重构为组件.md)），也反复用过模板自带的 SpringArm、Camera、Capsule。引擎其实自带了一大批现成组件——这篇是速查手册：**名称、作用、里面有什么**（常用属性 / 函数 / 事件）。

> 组件在编辑器"细节"面板看到的分类（Rendering、Physics、Audio……）和 C++ 继承体系是对应的。C++ 头文件基本都在 `Components/` 目录下，如 `#include "Components/SphereComponent.h"`。

---

## 〇、先看继承树（记住三个层级）

```
UActorComponent                    ← 最底层：只有"逻辑 + Tick"，没有位置
└── USceneComponent                ← 有 Transform（位置/旋转/缩放），可挂接成树
    ├── UArrowComponent / UBillboardComponent / UDecalComponent ...
    ├── UAudioComponent / UNiagaraComponent / ULightComponent 系
    ├── USplineComponent / UWidgetComponent / USceneCaptureComponent2D
    ├── UCameraComponent / USpringArmComponent
    └── UShapeComponent            ← 抽象的"形状"
        ├── UBoxComponent
        ├── USphereComponent
        └── UCapsuleComponent
    └── UMeshComponent             ← 抽象的"网格体"
        ├── UStaticMeshComponent
        ├── USkeletalMeshComponent
        └── USplineMeshComponent ...
└── UMovementComponent             ← 移动系（有逻辑无渲染，注意它不在 Scene 下）
    ├── UFloatingPawnMovement
    ├── URotatingMovementComponent
    ├── UProjectileMovementComponent
    └── UCharacterMovementComponent
```

选型规则（[第 3 章](/C++/3.组件编写与生命周期.md)讲过）：**要摆位置 → Scene 系；要渲染/碰撞 → Primitive 系（Mesh、Shape）；纯逻辑 → UActorComponent 系**。

`UPrimitiveComponent`（Mesh 和 Shape 的共同父类）集中了所有碰撞相关内容，单独立一节在最后。

## 一、形状与碰撞类（UShapeComponent 系）

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UCapsuleComponent` | 胶囊体碰撞，**Character 的默认根组件** | 属性：`CapsuleHalfHeight`、`CapsuleRadius`；函数：`SetCapsuleSize()`、`GetUnscaledCapsuleSize()` |
| `USphereComponent` | 球体碰撞，常用作触发器/检测范围 | 属性：`SphereRadius`；函数：`SetSphereRadius()`、`InitSphereRadius()` |
| `UBoxComponent` | 盒体碰撞，门、触发区域 | 属性：`BoxExtent`（半长宽高）；函数：`SetBoxExtent()` |

> 本项目的 `TargetActor` 练习类用的就是 `USphereComponent` 当根组件——形状组件因为"有变换 + 有碰撞但便宜（无渲染）"，是做 Trigger 区域的首选。

## 二、网格体类（UMeshComponent 系）

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UStaticMeshComponent` | 渲染静态网格体（关卡摆的墙、箱子都是它） | 函数：`SetStaticMesh()`、`SetMaterial()`；属性：碰撞预设、`bCastShadow` |
| `USkeletalMeshComponent` | 渲染骨骼网格体 + 驱动动画，**Character 的 `Mesh`** | 函数：`PlayAnimation()`、`SetAnimInstanceClass()`、`GetBoneLocation()`、`HideBoneByName()`；属性：`AnimationMode`（AnimationBlueprint / AnimationNode） |
| `USplineMeshComponent` | 让一个静态网格体沿样条**自动弯曲**（做路、围栏、河流） | 函数：`SetStartAndEnd()`、`SetSplineUpAxis()` |
| `UDynamicMeshComponent` | 程序化生成/修改网格体（UE5 新，取代旧的 ProceduralMeshComponent） | 函数：`GetDynamicMesh()` 后用 mesh editing API 改顶点 |

Character 里 `Mesh` 的冷知识：默认 `Mesh->SetupAttachment(GetCapsuleComponent())` 但旋转朝向是 -90°（骨骼前向是 X，骨骼资源朝 -Y），模板里能看到那行 `FRotator(0, -90, 0)`。

## 三、移动类（UMovementComponent 系）

特点：**只做逻辑不渲染**，控制"拥有者 Actor 怎么动"。

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UCharacterMovementComponent` | Character 专属的移动大脑：走/跑/跳/坠/游/飞的状态机 | 属性：`MaxWalkSpeed`、`JumpZVelocity`、`AirControl`、`BrakingDecelerationWalking`、`bOrientRotationToMovement`；函数：`AddImpulse()`、`SetMovementMode()`、`IsFalling()`、`IsMovingOnGround()`；事件（Character 上）：`OnMovementModeChanged` |
| `UProjectileMovementComponent` | 投射物飞行：直线/抛物线/追踪 | 属性：`InitialSpeed` / `MaxSpeed`、`ProjectileGravityScale`（0 = 不下坠）、`bRotationFollowsVelocity`、`bIsHomingProjectile` + `HomingTargetComponent`（追踪目标）；事件：`OnProjectileBounce`、`OnProjectileStop` |
| `URotatingMovementComponent` | 让 Actor 匀速自转（旋转机关、风扇） | 属性：`RotationRate`（每秒转多少度） |
| `UFloatingPawnMovement` | 给简单 Pawn 提供飞行移动（配合 AddMovementInput） | 属性：`MaxSpeed`、`Acceleration`、`Deceleration` |

> [第 13 章](/C++/13.LineTrace射线检测.md)的敌人如果不转整个 Actor，也可以只转 `Mesh`；但"匀速转头"用 `URotatingMovementComponent` 平滑插值更自然——这是组件拼装的典型思路。

## 四、相机类

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `USpringArmComponent` | "弹簧臂"：把相机撑到角色后上方，碰墙自动缩短，防穿墙 | 属性：`TargetArmLength`（臂长）、`SocketOffset` / `TargetOffset`、`bUsePawnControlRotation`、`bEnableCameraLag` + `CameraLagSpeed`（镜头拖尾）、`bDoCollisionTest` + `ProbeChannel`（穿墙检测）；常量：`SocketName`（臂末端插槽名，相机挂它） |
| `UCameraComponent` | 真正的相机：视场角、投影方式 | 属性：`FieldOfView`、`ProjectionType`（透视/正交）、`bConstrainAspectRatio`；本项目固定俯视角就是 `SetRelativeRotation(FRotator(-45, 0, 0))` 直接设定臂的旋转 |

两个组件是**父子树**：Camera 挂 SpringArm 的 `SocketName` 插槽，臂动相机跟着动——组件树的标准用法（[第 5 章](/C++/5.输入控制与第三人称相机.md)）。

## 五、灯光类（ULightComponent 系）

都是 SceneComponent 子类，属性面板大同小异：

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UDirectionalLightComponent` | 平行光：太阳/月亮，方向恒定，照亮全场景 | 属性：`Intensity`、`LightColor`、`AtmosphereSunLight`（联动天空大气） |
| `UPointLightComponent` | 点光源：灯泡，向四周衰减 | 属性：`Intensity`、`AttenuationRadius`（衰减半径）、`SourceRadius`（软阴影）、`bUseTemperature`（色温） |
| `USpotLightComponent` | 聚光灯：手电筒、舞台灯 | 额外属性：`InnerConeAngle` / `OuterConeAngle`（锥角） |
| `URectLightComponent` | 面光源：灯箱、屏幕（区域光） | 额外属性：`SourceWidth` / `SourceHeight` |
| `USkyLightComponent` | 天光：采集天空捕获低强度环境光 | 属性：`SourceType`（SLS_CapturedScene 采集场景）、`Intensity` |

## 六、特效与音频

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UNiagaraComponent` | 播放 Niagara 粒子特效（火、烟、雨） | 函数：`SetAsset()`、`Activate()` / `Deactivate()`；属性：`bAutoActivate` |
| `UParticleSystemComponent` | 旧版 Cascade 粒子（UE5 仅维护，新项目用 Niagara） | 函数：`SetTemplate()` |
| `UAudioComponent` | 播放声音（循环 BGM、3D 空间音效） | 函数：`SetSound()`、`Play()` / `Stop()`、`FadeIn()` / `FadeOut()`、`SetIntParameter()`（传参切音效）；属性：`bAutoActivate`、`VolumeMultiplier`；事件：`OnAudioFinished` |

## 七、辅助与工具类

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UArrowComponent` | 编辑器里画一个箭头指示"前向"，**打包后零开销**（模板 Character 就有一条） | 几乎没有内容，纯可视化辅助 |
| `UBillboardComponent` | 编辑器里显示一张贴图代表 Actor 位置（老式挂点标记） | 属性：`Sprite` |
| `UTextRenderComponent` | 在世界里渲染一行文字（3D 标牌） | 函数：`SetText()`、`SetTextColor()`；属性：`WorldSize`、`HorizontalAlignment` |
| `UDecalComponent` | 贴花：投影一张材质到表面（弹孔、血迹、魔法阵） | 函数：`SetDecalMaterial()`、`SetWorldScale3D()`；属性：`DecalSize`、`FadeStartDelay` / `FadeDuration`（自动淡出） |
| `USplineComponent` | 样条曲线：一条可编辑的路径点曲线（不渲染，供逻辑取点） | 函数：`AddSplinePoint()`、`GetLocationAtSplinePoint()`、`GetLocationAtTime()`、`SetSplinePointType()`；属性：`bClosedLoop` |
| `UChildActorComponent` | 把**另一个 Actor 整个**当作组件挂进来 | 属性：`ChildActorClass`、`ChildActorTemplate`；函数：`GetChildActor()` |
| `UWidgetComponent` | 把 UMG 控件渲染到世界里（头顶血条、广告牌） | 属性：`WidgetClass`、`DrawSize`、`Space`（Screen 固定屏幕 / World 跟随世界）、`bReceiveHardwareInput`（世界里能点它） |
| `USceneCaptureComponent2D` | 把场景拍摄到一张 RenderTarget（监控屏幕、镜子、小地图） | 属性：`TextureTarget`、`FOVAngle`、`ShowFlags`、`CaptureSource`；表亲 `USceneCaptureComponentCube` 拍立方体贴图 |

## 八、物理类

| 组件 | 作用 | 有哪些内容 |
|---|---|---|
| `UPhysicsConstraintComponent` | 把两个物体焊在一起做物理约束（铰链、弹簧、绳） | 属性：`ConstraintActor1` / `ConstraintActor2`、`ComponentName1` / `ComponentName2`；详细限制走 `ConstraintInstance`（位置锁 / 角度锁 / 软硬度）；事件：`OnComponentBroken()`（被拉断时广播，能拿到断裂位置） |
| `UPhysicsHandleComponent` | "手抓物体"：按住一个物理体跟随手柄目标移动（抓取/拖拽交互） | 函数：`GrabComponentAtLocation()`、`SetTargetLocation()`、`ReleaseComponent()`；属性：`InterpolationSpeed`（跟手平滑度） |

## 九、UPrimitiveComponent 公共内容（所有 Mesh/Shape 都有）

不管静态网格、骨骼网格还是胶囊球盒，碰撞和事件全在这一层：

**碰撞开关与响应**

```cpp
SetCollisionEnabled(ECollisionEnabled::QueryOnly);   // NoCollision / QueryOnly / PhysicsOnly / QueryAndPhysics
SetCollisionResponseToChannel(ECC_Visibility, ECR_Ignore);  // 对某通道 Block / Overlap / Ignore
SetCollisionObjectType(ECC_Pawn);                    // 自己"是"什么（对象通道）
GetCollisionResponseToChannel(...);                  // 查询
```

**三个最常用事件（委托，蓝图里是 OnComponentHit 等）**

| 委托 | 触发时机 | 典型用途 |
|---|---|---|
| `OnComponentHit` | 碰撞且至少一方在动（需要 Block） | 落地检测、子弹命中 |
| `OnComponentBeginOverlap` | 从不接触到接触（需要 Overlap） | 进入触发区（和[蓝图 5.3 旋转指针](/蓝图/5.制作场景地图/5.3旋转指针/旋转指针)触发器一致） |
| `OnComponentEndOverlap` | 从接触到离开 | 离开区域 |

C++ 绑定写法：

```cpp
SphereComp->OnComponentBeginOverlap.AddDynamic(this, &AMyActor::OnOverlap);
// 回调必须是 UFUNCTION() 标记的动态委托签名
UFUNCTION()
void OnOverlap(UPrimitiveComponent* OverlappedComp, AActor* OtherActor,
               UPrimitiveComponent* OtherComp, int32 OtherBodyIndex,
               bool bFromSweep, const FHitResult& SweepResult);
```

**渲染相关**：`SetVisibility()`、`SetHiddenInGame()`、`SetMaterial()`、`SetRelativeLocation()` 等；`UPrimitiveComponent` 名字里的 "Primitive" 就是渲染管线的"图元"。

## 十、查找组件的通用入口

拿到 Actor 后，不存成员指针也能按类型翻它的组件：

```cpp
// 找第一个指定类型的组件（含自己），找不到返回 nullptr
UStaticMeshComponent* MeshComp = FindComponentByClass<UStaticMeshComponent>();

// 找全部（含子类），例如收集所有点光源
TArray<UPointLightComponent*> Lights;
GetComponents(Lights);
```

反过来，组件找宿主用 `GetOwner()`（[第 14 章](/C++/14.实战-把视线检测重构为组件.md)的转身就是它）。

---

## 小结

- 记三个层级：**ActorComponent（逻辑）→ SceneComponent（有位置）→ Primitive（有渲染碰撞）**，选型先问"要不要摆位置、要不要看得见"；
- 常用组合速记：**相机 = SpringArm + Camera**；**角色 = Capsule + SkeletalMesh + CharacterMovement**；**投射物 = Sphere/Static + ProjectileMovement**；**触发器 = Shape + Overlap 事件**；
- 碰撞的开关、响应、三事件全在 `UPrimitiveComponent` 一层，学一次全套通用；
- 运行期按类型找组件：`FindComponentByClass<T>()` / `GetComponents<T>()`。
