# UE5 笔记写作

## 建新笔记

1. 新笔记放 `Docs/RPG/N.标题.md`，编号接续上一篇（当前到 16）；
2. 开头直入主题：不提旧工程、不提其他栏目章节、不堆文件清单；
3. 登记 `Docs/.vitepress/config.mts` 侧边栏 RPG 栏目——插在两个"查阅"条目**之前**；
4. Warrior 工程没有跳跃功能，笔记不写跳跃相关内容；
5. 发现疑似 bug：在笔记"细节与坑"小节标记"待改/存疑"，**不擅改用户代码**。

## 查阅页体系

两个查阅页收录正文里"一眼看不太懂"的东西，分工：

- `Docs/RPG/查阅-特殊语法速查.md`——**语言与宏**：模板、断言分级、反射宏要求、TSubclassOf/TSoftObjectPtr 等模板类型、前置声明、资产路径语法……
- `Docs/RPG/查阅-API速查.md`——**引擎 API**：函数怎么用、虚函数何时被调，按主题分组（Actor 与组件基础 / 移动与朝向 / 调试输出 / 标签与数据资产 / 输入管线 / 动画实例 / GAS / 武器与生成挂接）。

### 收录与链接规则（单向：笔记 → 查阅页）

1. **首次出现**的特殊语法 / UE API → 收进对应查阅页的分组；没有合适分组就新建一个，查阅页末尾的收尾句保持；
2. 笔记在**正文对应讨论位置**内联链接到查阅页（绝不在文末堆"参见"索引行）；
3. 链接文字必须**点名具体条目**（链接即查询词），如 `（Cast 两者对比见[速查](…#cast-与-castchecked)）`，不写泛泛的"涉及 API 详见"；
4. 链接一律**带小节锚点**跳到指定位置；
5. **查阅页绝不链接回笔记**——保持独立可查；两页之间只保留开头一句互相分工说明。

## 查阅页标题必须锚点友好

标题用纯关键词，**避免 `<T>`、`_C`、`/`、`()` 等符号**——它们在 VitePress slug 里会被吞成悬空残段：

- ✅ `TSubclassOf 类引用` → 锚点 `#tsubclassof-类引用`
- ✅ `Cast 与 CastChecked` → 锚点 `#cast-与-castchecked`
- ❌ `TSubclassOf<T>：类引用` → `#tsubclassof-t-类引用`（残段）
- ❌ `资产路径两套语法：_C 后缀与 /Script/` → `#资产路径两套语法-c-后缀与-script`

VitePress 锚点由标题渲染文本生成，规则要点（加锚点前先核对）：

- NFKD 归一化：全角标点（`：（）`）折成半角后按半角规则处理；
- 空格与 `~ \` ! @ # $ % ^ & * ( ) - _ + = [ ] { } | \ ; : " ' " " ' ' < > , . ? /` → 连字符；**下划线也变连字符**（`UE_LOG` → `ue-log`、`WARRIOR_API` → `warrior-api`）；
- 连续连字符合并为一个，去首尾连字符，转小写；中文原样保留；
- 标题以数字开头时数字前加 `_`。

拿不准就用等价 JS 验证：

```js
str.normalize("NFKD").replace(/[̀-ͯ]/g,"")
  .replace(/[\u0000-\u001f]/g,"")
  .replace(/[\s~`!@#$%^&*()\-_+=[\]{}|\\;:"'“”‘’<>,.?/]+/g,"-")
  .replace(/-{2,}/g,"-").replace(/^-+|-+$/g,"")
  .replace(/^(\d)/,"_$1").toLowerCase()
```
